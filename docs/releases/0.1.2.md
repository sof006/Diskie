A small release that tidies up updating.

**Already running 0.1.0 or 0.1.1?** Click the version at the bottom right of the window to check for updates now, instead of waiting for the daily check. Otherwise, download `Diskie-0.1.2-windows-x64.exe` and run it; it is a single portable file.

## Changed

- **The file name follows the version.** Updating used to leave the old name in place, so an updated copy could still be called `Diskie-0.1.0-windows-x64.exe`. Now it's renamed to match the new version (`Diskie-0.1.2-windows-x64.exe`).
  - Copies that 0.1.0 or 0.1.1 updated are renamed the first time 0.1.2 starts.
  - A copy you renamed yourself, such as `Diskie.exe`, keeps its name, and an existing file is never overwritten.
  - A shortcut or taskbar pin to the old name needs pinning again after the rename.
  - If an update fails to start and the previous version is put back, the file gets its old name back too.
- **The version at the bottom right has a tooltip** saying what clicking it does: check for updates, install the update, or restart to finish. After a failed update, the tooltip shows the full error.
