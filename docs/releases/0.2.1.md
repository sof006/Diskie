Fixes "Show in Explorer" and adds permanent delete.

**Already running Diskie?** Click the version at the bottom right of the window to update now.

## New

- **Delete permanently.** Press Shift+Del, or Shift+right-click an item and choose *Delete permanently…*.
  - Diskie asks first, and the item skips the Recycle Bin (Trash on Linux), so it can't be undone.
  - Where there is no Recycle Bin, such as a network share, the menu always offers it.
  - For a link or junction, only the link is deleted, never what it points to.
  - Read-only files are deleted too, as Explorer does.

## Fixed

- **"Show in Explorer" did nothing.** It now opens Explorer with the item selected, reusing an Explorer window that already shows that folder. On Linux, Diskie asks your file manager to show the item, or opens its folder, and says so if neither works.
- **The delete dialog said "1 folders".**
