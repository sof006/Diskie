Find what to clean up, not just what is big: search, largest files, duplicates, clean-up suggestions, and what changed since your last scan.

**Already running Diskie?** Click the version at the bottom right of the window to update now.

## New

- **Tabs above the tree:** *Largest files*, *Search*, *Duplicates*, *Clean-up* and *Changes*. Each covers the folder the treemap shows.
- **Search** from the box at the top (Ctrl+F). Besides names it understands `*.iso`, `>1GB`, `<10MB`, `older:2y`, `newer:30d`, `type:video`, `ext:log`, `is:folder`, `is:cloud`, `-word` to exclude and `"exact phrases"`.
- **Duplicates.** *Find duplicates* compares files of the same size by their first and last 64 KB, then in full. Hard links count once, and online-only cloud files are never downloaded. *Select extra copies* picks all but one of each, ready to delete.
- **Clean-up suggestions** for build output, `node_modules`, package and app caches, Temp, crash dumps, old downloads, `Windows.old`, WSL and Docker disks and more. Each says what it is and whether it is safe to delete, or better left to its own tool.
- **What changed.** Diskie keeps the last 5 scans of each place. The *Changes* tab lists what is new, grew, shrank or is gone since the previous scan, and you can pick an older scan to compare with.
- **Colour the treemap** by file type, by age, or by change since an earlier scan, with a legend on the right.
- **Live updates.** While a scan is open, changes on disk show up within a few seconds. The *Live* dot in the status bar turns it off.
- **Select several items** with Ctrl+click or Shift+click (Ctrl+A in a list), then delete, copy paths or use the menu on all of them. Several items moved to the Recycle Bin get a progress bar and Stop.
- **Recycle Bin sizes** for each drive in the sidebar, with *Empty*.
- **Cloud files** (OneDrive and others, on Windows): online-only files are tagged and not counted as using space. Right-click for *Free up space* or *Always keep on this device*.
- **Owner column**, from the *Owner* switch next to the tabs.
- **Export** what a tab lists (or the whole folder, from the tree) as CSV, or as JSON by naming the file `.json`.
- **Command line:** `Diskie scan <folder>` prints a summary, the folder tree and the largest files as JSON, or everything as CSV with `--csv`. See `Diskie --help`.

## Fixed

- With administrator rights, OneDrive and deduplicated files are no longer counted as empty links.
- `Diskie "C:\"` started from a command prompt now scans C:\ instead of failing.
