The first preview of Diskie, a fast disk space analyzer for Windows.

**Download** `Diskie-0.1.0-windows-x64.exe` and run it. It is a single portable file with no installer. Windows will ask for administrator rights (needed for the fastest scans). If you say no, Diskie still works, using the slower folder walk.

Windows SmartScreen may warn about an unrecognised app, because this build has no code-signing certificate yet. Choose *More info › Run anyway*. You can check the file against `SHA256SUMS`, or verify `Diskie-0.1.0-windows-x64.exe.minisig` with [minisign](https://jedisct1.github.io/minisign/) and the public key `RWRRXq4zLi5KCJ3HsnwyjUR7ZyQRdTrCqmbzn1mdw1UTV5tSSFYwkpqB`.

## What it does

- **Scans drives, folders and network shares.**
  - **As administrator, on NTFS:** reads the drive's Master File Table directly.
  - **Otherwise:** walks the folders in parallel, and slows to two threads on spinning hard disks, where many parallel reads are far slower.
  - **Network shares:** use *Scan folder or share…* and type a `\\server\share` path.
- **Tree and treemap, linked:**
  - Click a block to find it in the tree; double-click (or press Enter) to zoom in; Backspace goes back up.
  - Folders are drawn with header strips, so the hierarchy reads without hovering.
- **File types:** what kinds of files fill the folder you're looking at.
- **Clean up:** right-click for *Show in Explorer*, *Copy path* and *Move to Recycle Bin*. Diskie never deletes permanently, so it refuses on locations without a Recycle Bin, such as network shares.
- **Dark and light themes,** following Windows.
- **Updates itself:** once a newer release exists, the status bar offers it.
  - Every download is checked against its SHA-256 and a signature before anything is replaced.
  - If a new version fails to start twice, the previous one is put back.
  - Turn it off with `"updates": "off"` in `%APPDATA%\Diskie\settings.json`.

## Known gaps in this preview

- No reports (PDF, HTML, CSV) and no snapshots or comparisons yet.
- No search or filters yet.
- No settings screen yet.
- Mapped network drive letters don't appear in the drive list while Diskie runs as administrator (a Windows rule). Scan the `\\server\share` path instead.
- Windows only. Linux builds come later.
