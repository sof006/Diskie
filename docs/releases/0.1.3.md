Fixes the crash some of you hit after scanning a second drive.

**Already running 0.1.0 to 0.1.2?** Click the version at the bottom right of the window to check for updates now. Otherwise, download `Diskie-0.1.3-windows-x64.exe` and run it; it is a single portable file.

## Fixed

- **Diskie could crash when you scanned a drive after scanning a bigger one** in the same window.
  - A new scan could reuse the previous scan's treemap when the window size and zoom were unchanged.
  - That treemap was then drawn with the new scan's data. When the earlier scan was bigger, Diskie crashed; otherwise the treemap was simply wrong.
  - Each scan now gets its own treemap, and the old one is dropped as soon as a new scan finishes.
- **The crash message vanished before it could be read.** It now stays on screen until you click OK. The details are still saved to `%LOCALAPPDATA%\Diskie\crash.log`.
