A fix release for crashes during long first scans.

**Already running 0.1.0?** The status bar will offer this update. Otherwise, download `Diskie-0.1.1-windows-x64.exe` and run it; it is a single portable file.

## Fixed

- **A rare crash at the end of a slow first scan,** seen on a network share and on a hard disk that had to spin up. The exact cause isn't known yet, so this release makes sure it can't close the app again:
  - If the scan or the treemap runs into an internal error, Diskie now says so in the window instead of closing. You can rescan straight away.
  - The details go to `%LOCALAPPDATA%\Diskie\crash.log`. If you see the error, please attach that file to an issue, so the cause can be fixed properly.
  - Anything that still closes Diskie shows a message pointing to that file, instead of the window vanishing.
- **Mapped network drives:**
  - They're scanned like `\server\share` paths: with many requests at once, which is much faster over a network.
  - As administrator, Diskie no longer tries to read their Master File Table, which is on the server. The status bar no longer says it skipped that read because Diskie isn't running as administrator.
- **A failing folder-walk thread could hang the scan** or silently leave folders out. The scan now stops with an error instead.
